# Офіційні інструменти ШІ для Windows

Цей приватний проєкт зберігає відтворюваний стан встановлення та перевірки офіційних клієнтів і засобів командного рядка штучного інтелекту на Windows 11 без збереження таємних даних у сховищі.

Основні документи та матеріали:

- [КОНТРОЛЬНА-ТОЧКА-ІНСТРУМЕНТІВ-ШІ.uk.md](КОНТРОЛЬНА-ТОЧКА-ІНСТРУМЕНТІВ-ШІ.uk.md) — контрольна точка безпечного відновлення;
- [AI_TOOLS_INVENTORY.json](AI_TOOLS_INVENTORY.json) — машинозчитуваний перелік складників;
- [ПЕРЕВІРКА-ІНСТРУМЕНТІВ-ШІ.uk.md](ПЕРЕВІРКА-ІНСТРУМЕНТІВ-ШІ.uk.md) — підсумки приймальних перевірок і перешкоди;
- [РЕЄСТР-ОФІЦІЙНИХ-ДЖЕРЕЛ.uk.md](РЕЄСТР-ОФІЦІЙНИХ-ДЖЕРЕЛ.uk.md) — реєстр офіційних джерел постачальників;
- [МЕЖА-БЕЗПЕКИ.uk.md](МЕЖА-БЕЗПЕКИ.uk.md) — межа між підтримуваним доступом і небезпечною постійною системною лазівкою;
- [АГЕНТИ.uk.md](АГЕНТИ.uk.md) — правила безпечного налаштування та експлуатації агентів;
- [setup/phase0-audit.json](setup/phase0-audit.json) — очищене від чутливих відомостей початкове обстеження;
- [setup/policies/provider-policies.json](setup/policies/provider-policies.json) — перелік дозволених початкових каталогів і безпечні типові параметри сеансів для локальних агентів;
- [setup/scripts/Test-AIToolPreflight.ps1](setup/scripts/Test-AIToolPreflight.ps1) — попередня перевірка в режимі лише для читання перед запуском;
- [setup/rollback/ПОВЕРНЕННЯ-СТАНУ.uk.md](setup/rollback/ПОВЕРНЕННЯ-СТАНУ.uk.md) — посібник із повернення стану контрольованого запускача;
- [workspaces/ОГЛЯД.uk.md](workspaces/ОГЛЯД.uk.md) — дозволений кореневий каталог початкових робочих просторів контрольованого запускача.

Таємні дані тут не зберігаються. Надання доступу через OAuth, ключі API та платні рішення залишаються окремими діями винятково для власника.

Локальні агенти наразі не запускаються, оскільки контроль облікових записів користувачів (UAC) було вимкнено ще до створення цього проєкту. Стан диска `C:` із призупиненим захистом BitLocker відображається як окреме попередження. Відновлення цих засобів захисту потребує окремого рішення власника та, для UAC, перезавантаження Windows.

Перелік дозволених початкових каталогів не є ізольованим середовищем операційної системи: після окремого підтвердження засіб командної оболонки технічно може звернутися за абсолютним шляхом поза межами каталогу `workspaces`.
