# Штучні приймальні випробування / Gesimuleerde aanvaardingstests

## Українська (`uk`)

Кожне випробування окремого постачальника має використовувати лише власний дочірній каталог, створювати тимчасові файли з унікальними іменами, не записувати жодних таємних даних і видаляти лише процеси та файли, створені цим самим випробуванням.

Детальніше: [ОГЛЯД.uk.md](ОГЛЯД.uk.md).

---

## Nederlands (`nl`)

Elke aanbiederstest mag uitsluitend zijn eigen onderliggende map gebruiken, moet uniek benoemde tijdelijke bestanden aanmaken, mag geen geheimen vastleggen en mag uitsluitend processen en bestanden verwijderen die door die specifieke test zijn aangemaakt.

Meer informatie: [LEESMIJ.nl.md](LEESMIJ.nl.md).
