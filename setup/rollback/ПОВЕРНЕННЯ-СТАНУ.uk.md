# Повернення стану контрольованого запускача

Цей етап змінює лише файли, що відстежуються в приватному сховищі `C:\AI-Tools`. Він не змінює облікові дані, облікові записи постачальників, правила безпеки Windows, фонові служби, заплановані завдання, Захисник Windows, мережевий екран, контроль облікових записів (UAC) чи BitLocker.

Перед поверненням стану зафіксуйте поточний стан сховища:

```powershell
git -C C:\AI-Tools status --short --branch
git -C C:\AI-Tools rev-parse HEAD
```

Перегляньте цільову фіксацію змін перед відновленням. Відновлюйте лише шляхи, що належать цьому завданню:

```powershell
git -C C:\AI-Tools restore --source <перевірена-фіксація> -- `
  .gitignore `
  README.md `
  ОГЛЯД.uk.md `
  LEESMIJ.nl.md `
  КОНТРОЛЬНА-ТОЧКА-ІНСТРУМЕНТІВ-ШІ.uk.md `
  CONTROLEPUNT-AI-HULPMIDDELEN.nl.md `
  AI_TOOLS_INVENTORY.json `
  ПЕРЕВІРКА-ІНСТРУМЕНТІВ-ШІ.uk.md `
  VERIFICATIE-AI-HULPMIDDELEN.nl.md `
  РЕЄСТР-ОФІЦІЙНИХ-ДЖЕРЕЛ.uk.md `
  REGISTER-OFFICIELE-BRONNEN.nl.md `
  МЕЖА-БЕЗПЕКИ.uk.md `
  VEILIGHEIDSGRENS.nl.md `
  setup\README.md `
  setup\ОГЛЯД.uk.md `
  setup\LEESMIJ.nl.md `
  setup\scripts\README.md `
  setup\scripts\ОГЛЯД.uk.md `
  setup\scripts\LEESMIJ.nl.md `
  setup\scripts\Start-AITool.ps1 `
  setup\scripts\Test-AIToolPreflight.ps1 `
  setup\policies `
  setup\rollback\README.md `
  setup\rollback\ПОВЕРНЕННЯ-СТАНУ.uk.md `
  setup\rollback\TERUGDRAAIEN.nl.md `
  workspaces\README.md `
  workspaces\ОГЛЯД.uk.md `
  workspaces\LEESMIJ.nl.md
```

Не видаляйте облікові дані постачальників, встановлені застосунки, служби, заплановані завдання чи власні налаштування користувача під час цього повернення стану. Ці елементи виходять за межі цього етапу і могли існувати ще до початку проєкту.
