# Офіційні інструменти ШІ для Windows

Цей приватний проєкт зберігає відтворюваний стан встановлення та перевірки офіційних клієнтів і засобів командного рядка ШІ на Windows 11 без збереження секретів у репозиторії.

Основні артефакти:

- `AI_TOOLS_CHECKPOINT.md` — точка безпечного відновлення;
- `AI_TOOLS_INVENTORY.json` — машинозчитуваний реєстр компонентів;
- `AI_TOOLS_VERIFICATION.md` — результати приймальних перевірок і блокувальні чинники;
- `setup/phase0-audit.json` — очищений від чутливих даних початковий аудит;
- `SAFETY_BOUNDARY.md` — межа між підтримуваним доступом і небезпечним постійним системним обхідним шляхом;
- `setup/policies/provider-policies.json` — список дозволених початкових каталогів і безпечні типові параметри сеансів для локальних агентів;
- `setup/scripts/Test-AIToolPreflight.ps1` — попередня перевірка в режимі лише для читання перед запуском;
- `workspaces/` — дозволений кореневий каталог початкових робочих просторів контрольованого запускача.

Секрети тут не зберігаються. Авторизація OAuth, ключі API та платні рішення залишаються окремими діями винятково для власника.

Локальні агенти зараз не запускаються, оскільки контроль облікових записів користувачів (UAC) було вимкнено ще до створення цього проєкту. Стан диска `C:` із призупиненим захистом BitLocker відображається як окреме попередження. Відновлення цих засобів захисту потребує рішення власника та, для UAC, перезавантаження Windows.

Список дозволених початкових каталогів не є ізольованою пісочницею операційної системи: після окремого дозволу командна оболонка технічно може звернутися до абсолютного шляху поза межами `workspaces`.
