# Журнали перевірок / Verificatielogboeken

## Українська (`uk`)

Тут дозволено зберігати лише очищені від чутливих відомостей журнали перевірок, які не містять таємних даних. Поточні журнали виконання ігноруються засобом Git.

Детальніше: [ОГЛЯД.uk.md](ОГЛЯД.uk.md).

## Nederlands (`nl`)

Uitsluitend opgeschoonde, geheimvrije verificatielogboeken mogen hier worden bewaard. Uitvoeringslogboeken worden door Git genegeerd.
