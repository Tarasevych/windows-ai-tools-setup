# Зарезервоване місце для інтеграції Meta / Plaatsaanduiding voor Meta-koppeling

## Українська (`uk`)

Жодного локального агента Meta тут не встановлено, доки офіційна документація Meta не підтвердить доступність облікового запису, регіону та шляху API, а також підтримуваного інтерфейсу керування комп'ютером. Будь-який майбутній виконавець має бути явно позначений як локальна інтеграція, а не як офіційний настільний агент Meta для Windows, і не повинен розкривати облікові дані чи створювати неконтрольовану системну лазівку.

Детальніше: [ОГЛЯД.uk.md](ОГЛЯД.uk.md).

---

## Nederlands (`nl`)

Er wordt hier geen lokale Meta-agent geïnstalleerd totdat officiële documentatie van Meta een beschikbare route voor account, regio en API bewijst, evenals een ondersteunde koppelvlakvoorziening voor computerbediening. Elke toekomstige uitvoeringsvoorziening moet uitdrukkelijk worden aangeduid als een lokale koppeling en niet als een officiële Meta-bureaubladagent voor Windows, en mag geen aanmeldgegevens blootstellen of een onbeheerde achterpoort op systeemniveau vormen.

Meer informatie: [LEESMIJ.nl.md](LEESMIJ.nl.md).
