# Зарезервоване місце для інтеграції Meta

Жодного локального агента Meta тут не встановлено, доки офіційна документація Meta не підтвердить доступність облікового запису, регіону та шляху API, а також підтримуваного інтерфейсу керування комп'ютером. Будь-який майбутній засіб виконання має бути явно позначений як локальна інтеграція, а не як офіційний настільний агент Meta для Windows, і не повинен розкривати облікові дані чи створювати неконтрольовану системну лазівку.
