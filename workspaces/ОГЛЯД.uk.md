# Схвалені робочі простори ШІ

Контрольований запускач приймає лише цей каталог та його дочірні підкаталоги. Створюйте один дочірній каталог для кожного окремого завдання чи проєкту. Не розміщуйте тут облікові дані, профілі оглядача, сховища паролів, коди відновлення чи сторонні приватні відомості.

Локальні агенти запускаються із запитами підтвердження дій від постачальника, запитами довіри до каталогу, без віддаленого керування та без фонових налаштувань MCP. Виконання з підвищеними правами заблоковано; також запуск локальних агентів заблоковано, доки вимкнено контроль облікових записів (UAC).
