# Схвалені робочі простори ШІ / Goedgekeurde AI-werkruimten

## Українська (`uk`)

Контрольований запускач приймає лише цей каталог та його дочірні підкаталоги. Створюйте один дочірній каталог для кожного окремого завдання чи проєкту. Не розміщуйте тут облікові дані, профілі оглядача, сховища паролів, коди відновлення чи сторонні приватні відомості.

Локальні агенти запускаються із запитами підтвердження дій від постачальника, запитами довіри до каталогу, без віддаленого керування та без фонових налаштувань MCP. Виконання з підвищеними правами заблоковано; також запуск локальних агентів заблоковано, доки вимкнено контроль облікових записів (UAC).

Детальніше: [ОГЛЯД.uk.md](ОГЛЯД.uk.md).

## Nederlands (`nl`)

De gecontroleerde startvoorziening aanvaardt uitsluitend deze map en de onderliggende submappen. Maak één onderliggende map per taak of project aan. Plaats hier geen aanmeldgegevens, webbrowserprofielen, wachtwoordkluizen, herstelmateriaal of ongerelateerde privégegevens.

Lokale agenten starten met goedkeuringsvragen van de aanbieder, vertrouwensvragen van de aanbieder, zonder bediening op afstand en zonder omgevingsgebonden MCP-instellingen. Uitvoering met verhoogde rechten is geblokkeerd, en het starten van lokale agenten is eveneens geblokkeerd zolang gebruikersaccountbeheer (UAC) is uitgeschakeld.

Meer informatie: [LEESMIJ.nl.md](LEESMIJ.nl.md).
