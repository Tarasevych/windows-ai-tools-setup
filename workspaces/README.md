# Approved AI workspaces

The controlled launcher accepts this directory and its descendants only.
Create one child directory per task or project. Do not place credentials,
browser profiles, password stores, recovery material, or unrelated private
data here.

Local agents start with provider approval prompts, provider trust prompts, no
remote control, and no ambient MCP configuration. Elevated execution is
blocked, and local-agent launch is also blocked while UAC is disabled.
